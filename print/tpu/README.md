# TPU plate: grip pads + speaker washers, Snapmaker U1

- TPU on **head 4 (T3)**, the TPU slot in all the U1 files. Heads 1-3 aren't used on this plate.
- `TPU_U1.3mf`: full project (printer, process, filaments). `TPU_model.3mf`: model only, so your own presets stay selected.
- Snapmaker TPU 95A HF profile: 230 °C nozzle, engineering plate at 30 °C, 0.2 mm layers, 100 % infill, 2 walls.
- A 3 mm brim on the small speaker washers only (they're tiny and would otherwise lift); none on the grip pads.
- About 7 min and 3 g.
- Rebuild with `cad/slice_tpu.py`.
